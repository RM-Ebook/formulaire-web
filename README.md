# Formulaire d'inscription client

Formulaire web responsive permettant l'inscription de clients pour recevoir des offres exclusives.

## Fonctionnalités

- Saisie des informations client : nom, prénom, email, mobile, date de naissance, code postal
- Validation des champs en JavaScript (format email, numéro de téléphone à 10 chiffres, date jj/mm/aaaa, code postal à 5 chiffres)
- Message de confirmation ou d'erreur après soumission
- Envoi des données vers une API externe via requête HTTP GET
- Bouton de réinitialisation du formulaire

## Technologies utilisées

- HTML5
- CSS3
- JavaScript (Vanilla)
